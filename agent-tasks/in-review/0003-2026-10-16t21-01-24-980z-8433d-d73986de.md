## Root cause

Sister task 0002 (same log events) shows the context: on 2026-10-16 sercekawy.pl served an expired
TLS certificate, so every `fetch` from the `flagRemoved` Lambda failed TLS verification. undici wraps
this as a generic `TypeError: fetch failed`, and the handler's catch block logs the raw error object
first (`logger.error(error)`), which is exactly this task's signature — the meaningful cause
(`certificate has expired`, `code: 'CERT_HAS_EXPIRED'`) is buried in the `[cause]` property and the
opaque undici stack dominates the error signature. 88 occurrences, all on 2026-10-16.

Reproduced locally: ran an HTTPS server with an expired certificate (issued via `openssl ca` with
`notAfter` in the past) and called `fetch` with the handler's exact options (`redirect: 'manual'`,
undici `Agent` dispatcher) — the current code logs precisely this task's signature:
`TypeError: fetch failed at Object.processResponse (undici/lib/web/fetch/index.js:272:16)` with
`[cause]: Error: certificate has expired { code: 'CERT_HAS_EXPIRED' }`.

The roaster renewed the certificate on 2026-10-17 (current chain: CN=www.sercekawy.pl, issued by
Shoper DV TLS G2 R34 CA, valid to 2027-05-04); a live fetch of the affected URL
(https://sercekawy.pl/pl/p/ZACHWYT-FILTER/106) now returns 200. No coffee was wrongly flagged as
removed — the handler correctly returns without flagging on fetch failure.

## Fix

`packages/flag-removed/src/index.js`: log the undici cause instead of the wrapper in the catch
block (`logger.error(error.cause || error)`). The console signature and the Sentry capture now
surface `Error: certificate has expired { code: 'CERT_HAS_EXPIRED' }` directly instead of the
unactionable `TypeError: fetch failed` undici stack. Behavior is unchanged otherwise.

Verified: the local expired-cert repro now logs the cause error as the first line; a live fetch of
the affected URL returns 200; `yarn lint` passes. The workspace test script
(`yarn workspace @centralbeans/flag-removed test`) is a live integration script requiring AWS
secrets (`.env`) and could not be run in this environment.
